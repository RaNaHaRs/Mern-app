================================================================================
NEW ENDPOINTS
================================================================================

Payment Link Service (3 endpoints)

1. POST /api/payment-link/generate
   ├─ Generate shareable payment links
   ├─ Input: amount, plan_key, months, email, name
   ├─ Output: link_id, payment_link URL, status
   └─ Purpose: Create links for sharing

2. GET /api/payment-link/:link_id
   ├─ Retrieve link details
   ├─ Input: link_id
   ├─ Output: Link info, amount, plan, status
   └─ Purpose: View link details

3. POST /api/payment-link/:link_id/checkout
   ├─ Convert link to Razorpay checkout
   ├─ Input: link_id, optional customer info
   ├─ Output: order_id, key_id for checkout
   └─ Purpose: Initiate checkout from link

Admin Endpoint (1 endpoint)

4. POST /api/super-admin/tenants/:id/upgrade-plan
   ├─ Admin-initiated plan upgrade/renew
   ├─ Input: tenant_id, new_plan, months
   ├─ Output: order_id, key_id for checkout
   └─ Purpose: Upgrade subscriber plan
