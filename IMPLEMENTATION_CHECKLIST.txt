DATABASE SCHEMA
================================================================================

NEW TABLE: payment_links

CREATE TABLE payment_links:
✅ id (UUID PRIMARY KEY)
✅ tenant_user_id (UUID, nullable for new subscribers)
✅ purchase_id (UUID, nullable, links to saas_purchases)
✅ razorpay_order_id (VARCHAR, stores Razorpay order ID)
✅ plan_key (VARCHAR NOT NULL)
✅ plan_label (VARCHAR)
✅ amount (DECIMAL NOT NULL)
✅ months (INTEGER NOT NULL)
✅ description (TEXT, optional)
✅ customer_email (VARCHAR)
✅ customer_name (VARCHAR)
✅ status (VARCHAR DEFAULT 'active')
   ├─ Values: active, checkout_initiated, paid, expired, cancelled
   └─ Prevents duplicate payments
✅ expires_at (TIMESTAMP, optional expiration)
✅ created_by (UUID, audit trail)
✅ created_at (TIMESTAMP DEFAULT NOW())
✅ updated_at (TIMESTAMP DEFAULT NOW())

INDEXES:
✅ idx_payment_links_status - Fast status queries
✅ idx_payment_links_tenant - Fast tenant lookup
✅ idx_payment_links_created - Timeline queries
✅ idx_payment_links_purchase - Link to purchase

FOREIGN KEYS:
✅ tenant_user_id → users(id) ON DELETE CASCADE
✅ purchase_id → saas_purchases(id) ON DELETE SET NULL

✅ saas_purchases - no changes

API ENDPOINTS VERIFICATION
================================================================================

PAYMENT LINK SERVICE:

✅ POST /api/payment-link/generate
   Input:  amount, plan_key, plan_label, months, description, customer_email, customer_name
   Output: link_id, payment_link, amount, status, created_at
   Status: 422 on validation error, 500 on Razorpay error

✅ GET /api/payment-link/:link_id
   Input:  link_id in URL
   Output: Link details (amount, plan, status, created_at)
   Status: 404 if not found, 500 on error

✅ POST /api/payment-link/:link_id/checkout
   Input:  link_id in URL, optional email/name
   Output: order_id, purchase_id, key_id for checkout
   Status: 400 if expired/inactive, 500 on Razorpay error

ADMIN ENDPOINTS:

✅ POST /api/super-admin/tenants/:id/upgrade-plan
   Input:  tenant_id in URL, new_plan, months in body
   Output: order_id, purchase_id, key_id for checkout
   Auth:   Requires super_admin permission
   Status: 404 if tenant not found, 500 on Razorpay error
