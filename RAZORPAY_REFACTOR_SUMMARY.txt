================================================================================
API REFERENCE
================================================================================

GENERATE PAYMENT LINK:
POST /api/payment-link/generate
Input:  amount, plan_key, months, customer_email, customer_name
Output: link_id, payment_link URL, amount, status

GET LINK DETAILS:
GET /api/payment-link/:link_id
Output: Link details, amount, plan, status

INITIATE CHECKOUT:
POST /api/payment-link/:link_id/checkout
Output: order_id, purchase_id, key_id for checkout

ADMIN UPGRADE/RENEW:
POST /api/super-admin/tenants/:id/upgrade-plan
Input:  new_plan, months
Output: order_id, purchase_id, key_id for checkout

NEW PAYMENT LINK WORKFLOW
================================================================================

STEP 1: Generate Link
├─ Input: plan, months
├─ Backend: creates payment_links record
├─ Output: shareable URL

STEP 2: Display Link
├─ Show URL to customer/admin
├─ Provide copy button
├─ Display amount, plan, status

STEP 3: Customer clicks link
├─ Loads payment-link/:id/checkout
├─ Creates Razorpay order
├─ Opens checkout

STEP 4: Payment
├─ Customer completes payment
├─ Signature verified
├─ Subscriber created
├─ Invoice generated

ADMIN UPGRADE/RENEW WORKFLOW
================================================================================

STEP 1: Admin clicks upgrade
├─ Input: tenant, new_plan, months
├─ Backend: creates Razorpay order
├─ Frontend: opens checkout modal

STEP 2: Payment
├─ Customer completes payment

├─ Invoice generated
