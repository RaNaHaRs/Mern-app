# 🎨 Branding Upload - Quick Guide

## How to Upload Logo & Favicon

### Step 1: Access Branding Settings
1. Login as Super Admin
2. Navigate to **Super Admin** page
3. Click on **Branding** tab

### Step 2: Upload Logo

#### Visual Preview
```
╔═══════════════════════════════════════╗
║  Platform Identity                    ║
╟───────────────────────────────────────╢
║                                       ║
║  Logo                    Favicon      ║
║  ┌───────────────────┐  ┌──────────┐ ║
║  │                   │  │          │ ║
║  │   Your Logo       │  │  Icon    │ ║
║  │   Appears Here    │  │  Here    │ ║
║  │                   │  │          │ ║
║  └───────────────────┘  └──────────┘ ║
║                                       ║
║  [Change Logo] [Remove]               ║
║  Or paste URL: ___________            ║
║  Recommended: PNG, 200×60px           ║
║                                       ║
╚═══════════════════════════════════════╝
```

#### Upload Process:
1. Click **"Upload Logo"** button
2. Select your image file (JPG, PNG, SVG, etc.)
3. ✅ Preview appears **instantly**
4. ✅ File uploads in background
5. ✅ See your logo immediately!

### Step 3: Upload Favicon

Same process as logo:
1. Click **"Upload Favicon"** button
2. Select small icon file (32×32px or 64×64px recommended)
3. ✅ Preview appears instantly
4. ✅ See your favicon in the tab!

### Step 4: Save Settings

Click **"Save Branding Settings"** at the bottom to apply changes across the entire application.

## Supported Image Formats

### ✅ Accepted Formats
- **JPG/JPEG** - Standard photos
- **PNG** - Transparent backgrounds (recommended for logos)
- **GIF** - Animated images
- **SVG** - Vector graphics (scalable, recommended)
- **WebP** - Modern format
- **ICO** - Favicon format

### ❌ Not Accepted
- PDF files
- Word documents
- Videos
- Other non-image files

## Size Requirements

| Type | Max Size | Recommended Dimensions |
|------|----------|----------------------|
| **Logo** | 5MB | 200×60px (PNG/SVG) |
| **Favicon** | 5MB | 32×32px or 64×64px |

## Best Practices

### Logo
✅ **DO:**
- Use PNG with transparent background
- Use SVG for perfect scaling
- Keep it simple and readable
- Use horizontal layout (wider than tall)
- Test on light and dark backgrounds

❌ **DON'T:**
- Use photos or complex images
- Use very tall/vertical logos
- Use low resolution images
- Include small text that won't be readable

### Favicon
✅ **DO:**
- Use simple, recognizable icon
- Use square dimensions (32×32, 64×64)
- Test at small sizes
- Use high contrast colors

❌ **DON'T:**
- Use detailed logos
- Use text-heavy designs
- Use very light colors

## Error Messages

### File Type Error
```
❌ Please upload a valid image file 
   (JPG, PNG, GIF, SVG, WebP, or ICO)
```
**Solution:** Choose a different file format

### File Size Error
```
❌ File size must be less than 5MB
```
**Solution:** Compress your image or choose smaller file

### Upload Failed
```
❌ Upload failed: [error details]
```
**Solution:** Check internet connection, try again

### Image Load Failed
```
⚠️ Failed to load image
```
**Solution:** Check URL, try re-uploading

## Alternative: Paste Image URL

Don't want to upload? You can paste an external image URL:

1. Find your image online
2. Copy the image URL (must end with .jpg, .png, etc.)
3. Paste into the "Or paste URL" field
4. Image appears immediately!

Example URLs:
```
✅ https://example.com/logo.png
✅ https://cdn.example.com/images/favicon.ico
❌ https://example.com/page (not an image)
```

## Quick Troubleshooting

### Logo not appearing?
- ✅ Check file format (must be image)
- ✅ Check file size (under 5MB)
- ✅ Try different browser
- ✅ Clear cache and reload

### Favicon not updating?
- ✅ Click "Save Branding Settings"
- ✅ Hard refresh browser (Ctrl+F5)
- ✅ Close and reopen tab
- ✅ Clear browser cache

### Preview looks wrong?
- ✅ Check image dimensions
- ✅ Use recommended sizes
- ✅ Try different image format
- ✅ Remove and re-upload

### Upload button not working?
- ✅ Check browser console for errors
- ✅ Check internet connection
- ✅ Check file permissions
- ✅ Try different file

## Pro Tips

### 💡 Tip 1: Use SVG for Logo
SVG files scale perfectly at any size and stay crisp.

### 💡 Tip 2: Test Colors
Make sure your logo works on both light and dark backgrounds.

### 💡 Tip 3: Keep It Simple
Simple logos work better at small sizes (like in the favicon).

### 💡 Tip 4: Use Brand Colors
Match your logo colors with the Primary/Accent color settings.

### 💡 Tip 5: Test Before Saving
Preview looks perfect? Great! If not, try a different image.

### 💡 Tip 6: Backup Original Files
Keep your original high-res logo files safe for future use.

### 💡 Tip 7: Update Regularly
Refresh your branding for special occasions or rebranding.

## Need Help?

### Common Questions:

**Q: Can I use a photo as my logo?**
A: Yes, but simple graphics work better. Photos can look cluttered at small sizes.

**Q: Why isn't my logo showing?**
A: Make sure you clicked "Save Branding Settings" after uploading.

**Q: Can I change the logo later?**
A: Yes! Just upload a new one and click "Change Logo".

**Q: What if I don't have a favicon?**
A: You can create one from your logo using online converters like favicon.io

**Q: Can I use the same image for logo and favicon?**
A: Yes, but the favicon will be very small (32px). Consider using a simplified version.

**Q: Does it affect performance?**
A: No! Images are cached and load very quickly.
