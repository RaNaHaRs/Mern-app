================================================================================
TROUBLESHOOTING
================================================================================

ISSUE: "payment-link route not found" (404 error)
SOLUTION:
1. Verify index.js has the import and app.use() lines
2. Check file was copied to correct location
3. Restart backend
4. Try again

ISSUE: "payment_links table does not exist" (500 error)
SOLUTION:
1. Check migration file was copied to migrations folder
2. Check migrate.js has the new migration entry
3. Restart backend (migration runs automatically)
4. Check database: SELECT * FROM information_schema.tables WHERE table_name='payment_links';
5. If table doesn't exist, manually run the SQL

ISSUE: "Razorpay credentials not configured" (500 error)
SOLUTION:
1. Go to Super Admin → Email Deliverability
2. Enter Razorpay credentials
3. Click "Save SMTP Settings"
4. See ✅ confirmation message
5. Try again

ISSUE: Payment link created but checkout won't open
SOLUTION:
1. Check Razorpay credentials are saved
2. Check credentials are valid (start with rzp_test_ or rzp_live_)
3. Check browser console (F12) for JavaScript errors
4. Clear browser cache and try again

ISSUE: "Tenant not found" when upgrading
SOLUTION:
1. Verify you're using correct tenant ID
2. Check tenant exists in database
3. Verify you have super_admin permission
4. Check user token is valid
